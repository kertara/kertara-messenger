# Contributing to Kertara Messenger

First of all, thank you for your interest in improving **Kertara Messenger**! We welcome contributions that help make this project more secure, private, and stable.

## How to Contribute

### 1. Reporting Bugs

* **Search for existing issues:** Check if the bug has already been reported.
* **Provide details:** If it's a new bug, include your OS version, steps to reproduce, and any relevant error logs or screenshots.

### 2. Proposing Features

* Open an issue to discuss your idea before writing code. This saves you time and ensures your contribution aligns with our project goals.

### 3. Pull Requests (PRs)

* **Branching:** Create a new branch for your feature or fix (e.g., `feature/add-new-ui` or `fix/tor-connection-timeout`).
* **Code Style:** Keep your code clean, readable, and well-commented.
* **Documentation:** If you add a new feature, please update the documentation or mention it in the PR description.
* **Testing:** Ensure your changes don't break the existing build process described in `BUILD.md`.

## Development Workflow

1. Fork the repository.
2. Clone your fork locally.
3. Create your feature branch.
4. Make your changes and commit them with descriptive messages.
5. Push to your branch and submit a Pull Request to the `main` branch.

## Code of Conduct

By participating in this project, you agree to abide by our [Code of Conduct](https://github.com/kertara/kertara-messenger/blob/main/CODE_OF_CONDUCT.md). Please be respectful and professional in your interactions.
