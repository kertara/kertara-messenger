##**Kertara Messenger**
Kertara Messenger is a privacy-focused communication platform that prioritizes user data security through end-to-end encryption and anonymous routing via the Tor network.

**Key Features**
- End-to-End Encryption: All messages are encrypted directly on your device; only you and the recipient can read them.
- Maximum Privacy: Uses the Tor network to keep your identity and location hidden from surveillance.
- Local Data Storage: Your contact list and security keys are stored locally on your device. Kertara has no access to your private data or message history.
- Full Control: You retain complete control over your identity and contact list without third-party interference.

**Installation Guide**
1. Download the latest release package (.rar) from the Releases section.
2. Extract the files to a folder on your computer.
3. Run Kertara.exe.
4. Upon the first launch, please wait a few moments for the Tor connection to initialize (the status indicator will reach 100%).
