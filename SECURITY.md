# Security Policy

We take the security of **Kertara Messenger** very seriously. Since this project focuses on privacy and anonymity, we appreciate the community's help in identifying and reporting security vulnerabilities.

## Reporting a Vulnerability

If you have discovered a potential security vulnerability, please **do not report it in the public issue tracker**. Disclosing vulnerabilities publicly puts our users at risk.

Please send a private email to the project maintainer at:
**[contact@kertara.app]**

### What to include in your report:

* **Description:** A clear description of the vulnerability.
* **Impact:** What could an attacker achieve with this vulnerability?
* **Steps to Reproduce:** Instructions on how to trigger the vulnerability.
* **Environment:** System details (OS, version, etc.).

We will acknowledge your report within 48 hours and work with you to fix the issue before it is made public.

## Security Updates

All security patches will be documented in the release notes for the affected versions.
